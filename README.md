# Telegram Mini App — Блокноты (Предзаказ)

Удобный Telegram-бот с интегрированным Web App (Mini App) для просмотра каталога и оформления предзаказов на фирменные блокноты.

## Функционал
* **Интерактивная витрина:** Слайдер с изображениями, описанием и ценами товаров внутри Telegram.
* **Оформление предзаказа:** Форма сбора контактных данных (имя, телефон, комментарий) напрямую через интерфейс Mini App.
* **Уведомления:** Мгновенная отправка данных о новом предзаказе в приватный Telegram-чат администратора.
* **Работа 24/7:** Настроен внешний мониторинг для предотвращения ухода сервера в спящий режим.

## Стек технологий
* **Frontend:** HTML5, CSS3 (адаптивная вёрстка под экраны смартфонов), JavaScript (Telegram Web Apps API).
* **Backend:** Python 3, Flask (REST API для обработки заказов и вебхуков Telegram), Requests.
* **Hosting:** Render (Бэкенд), GitHub Pages (Фронтенд).

## Структура проекта
* `main.py` — Flask-сервер, обрабатывающий запросы от Mini App и взаимодействующий с Telegram API.
* `index.html` — Фронтенд-часть приложения (интерфейс Web App).
* `notebook.jpg` — Изображение товара для витрины.
* `requirements.txt` — Список зависимостей для быстрой установки бэкенда.

## Настройка окружения (для администратора)
Для работы бота на сервере должны быть заданы следующие переменные окружения (Environment Variables):
* `BOT_TOKEN` — Уникальный токен бота, полученный от @BotFather.
* `CHANNEL_ID` — ID Telegram-чата, куда бот должен пересылать входящие предзаказы.
